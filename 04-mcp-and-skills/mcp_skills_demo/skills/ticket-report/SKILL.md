# 工单周报

## 数据来源

工单数据从 `scripts/build_report.py` 产出。运行方式：

```
python skills/ticket-report/scripts/build_report.py --days 7
```

脚本只读，不会改动任何业务数据。

## 报告结构

固定四段，顺序不要变。

第一段，总量与环比。第二段，退款原因分布，按占比降序。第三段，超时工单清单，带上停留时长。第四段，下周建议，不超过 3 条。

## 输出格式

正文控制在 400 字以内。数字用阿拉伯数字。

表格只放三段：原因分布、超时清单、环比对照。不要给每一段都配表格。

## 口径

统计口径按工单创建时间，不按处理时间。

跨周工单只计入创建周，避免重复统计。

作废工单不计入总量，但在原因分布里单独列一行说明。
